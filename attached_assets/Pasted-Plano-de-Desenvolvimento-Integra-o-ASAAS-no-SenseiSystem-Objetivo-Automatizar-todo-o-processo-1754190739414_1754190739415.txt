Implemente a integração com o ASAAS neste projeto SaaS (SenseiSystem) com as seguintes etapas:

1. Ao aprovar um cliente (tenant), crie um cliente na API do ASAAS e salve o `asaasCustomerId`.
2. Todo mês, crie uma cobrança automática com valor e vencimento definido.
3. Armazene os pagamentos na tabela `school_payments`.
4. Crie um webhook `/webhooks/asaas` para processar os status de pagamento.
5. Se houver atraso > 10 dias, bloqueie o tenant e envie aviso por email/WhatsApp.
6. Crie um painel de controle de pagamentos para o Superadmin com histórico e status dos tenants.

Use o dashboard já criado com Shadcn/UI para exibir os cards de status financeiro. A API
