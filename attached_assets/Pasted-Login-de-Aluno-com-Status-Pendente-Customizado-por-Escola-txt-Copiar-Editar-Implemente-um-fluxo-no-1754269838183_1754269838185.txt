Implemente um fluxo no sistema SenseiSystem (React + Node.js + Tailwind + multitenancy) onde, ao se cadastrar, um aluno recebe status "pendente" e, mesmo podendo fazer login, é redirecionado automaticamente para uma página de “Aguardando aprovação”.

🎯 Objetivo:
Permitir que o aluno logue, mas impedir o acesso ao sistema até que a administração da escola aprove o cadastro e vincule um plano.

🔧 Requisitos técnicos:

1. **Banco de dados (ex: Prisma)**
- Campo na entidade `Aluno` ou `User`: `status` com os valores possíveis: `"pendente"`, `"ativo"`, `"inativo"`

2. **Lógica de login (Node ou API de autenticação)**
- Se `status === 'pendente'`, permitir login normalmente
- Mas redirecionar para a rota `/aguardando-aprovacao` após autenticação

3. **Middleware de rotas protegidas**
- Se o usuário estiver logado, mas `status !== 'ativo'`, bloquear o acesso às rotas internas
- Middleware deve redirecionar para `/aguardando-aprovacao`

4. **Página: `/aguardando-aprovacao.tsx`**
- Layout limpo e informativo com:
  - Logotipo da escola (dinâmico com base no `tenant`)
  - Nome da escola (ex: Huios Jiu Jitsu)
  - Nome do aluno (via sessão ou JWT)
  - Mensagem customizada como:
```jsx
<h1>Olá, [NOME_DO_ALUNO]!</h1>
<p>Seu cadastro foi recebido com sucesso pela <strong>[NOME_DA_ESCOLA]</strong>.</p>
<p>Agora estamos analisando suas informações e em breve seu acesso será liberado.</p>
<p className="text-gray-500">Assim que a escola vincular seu plano de pagamento, você será notificado por e-mail ou WhatsApp.</p>
