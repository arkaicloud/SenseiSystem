🎯 Tarefa:
Implementar o fluxo de cadastro e login de novos alunos no SenseiSystem. Após o aluno clicar em “Matricule-se” no menu, ele será redirecionado para a tela de criação de conta e, após login bem-sucedido, será automaticamente direcionado para o fluxo de onboarding obrigatório, com salvamento de progresso etapa a etapa.

---

## 📍 Etapas do fluxo:

### 1. Rota `/cadastro` (Matricule-se)
Tela com 3 campos:
- Nome completo
- E-mail
- Senha

Validações:
- Mínimo 8 caracteres
- Pelo menos 1 número
- Pelo menos 1 caractere especial
- Feedback visual conforme digita

Botão: `Criar conta`

---

### 2. Backend (API)
- `POST /api/aluno/cadastrar` → cria conta com `status = "pendente"` e `onboardingCompleto = false`
- Após sucesso, redirecionar para login automático ou `/login` com feedback

---

### 3. Rota `/login`
- Campos: e-mail e senha
- Autenticação JWT ou session
- Após login:
  - Se `onboardingCompleto = false` → redirecionar para `/onboarding`
  - Se `onboardingCompleto = true` → redirecionar para `/dashboard`

---

### 4. Rota `/onboarding`
Fluxo multi-etapas guiado com progresso salvo a cada tela:
1. Dados Pessoais
2. Contato e Endereço
3. Responsável Financeiro
4. Plano
5. Questionário de Saúde
6. Aceite de Contrato
