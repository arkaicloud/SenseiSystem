2. Overdue Payments – Definition
Display the number of overdue student payments in the current tenant.

Conditions:

Use the table student_payments

Filter by status = 'overdue'

Join with students → users → school_config to scope by tenant

Consider only students with users.active = true

Query logic:

sql
Copiar
Editar
SELECT COUNT(*)
FROM student_payments sp
JOIN students s ON sp.studentId = s.userId
JOIN users u ON s.userId = u.id
WHERE sp.status = 'overdue'
  AND u.active = true
  AND u.status = 'active'
  AND u.tenantId = CURRENT_TENANT;

4. Frontend Integration
Use useEffect + setInterval to fetch the /api/admin/widgets/engagement endpoint every 5 minutes

Display values in UI cards with color coding and icons

useEffect(() => {
  const fetchWidgets = async () => {
    const res = await fetch('/api/admin/widgets/engagement');
    const data = await res.json();
    setWidgets(data);
  };

  fetchWidgets();
  const interval = setInterval(fetchWidgets, 5 * 60 * 1000);

  return () => clearInterval(interval);
}, []);
