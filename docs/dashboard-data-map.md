= 'active'` AND `users.active = true`  \n**SQL:** `COUNT(*) FROM students JOIN users WHERE users.status='active' AND users.active=true`  \n**Janela Temporal:** Atual (sem filtro de tempo)  \n\n### Taxa de Presença\n**Definição:** Porcentagem de presenças confirmadas sobre o total de presenças esperadas no período  \n**SQL:** `(COUNT(CASE WHEN status='present' THEN 1 END) / COUNT(*)) FROM attendance WHERE date BETWEEN fromDate AND toDate`  \n**Janela Temporal:** Mês atual ou período configurado  \n\n### Receita Mensal\n**Definição:** Soma dos pagamentos recebidos no período atual de ambas as fontes (studentPayments + contasReceber)  \n**SQL:** `SUM(studentPayments.amount) + SUM(contasReceber.value) WHERE status IN ('paid', 'RECEIVED') AND date IN period`  \n**Janela Temporal:** Mês atual (configurável)  \n**Unidade:** Centavos (convertido para BRL no frontend)  \n\n### Alunos em Risco\n**Definição:** Estudantes ativos sem registro de presença nos últimos X dias (configurável via businessRules)  \n**SQL:** `COUNT(*) FROM students LEFT JOIN attendance WHERE attendance.date > (now - X days) AND attendance.id IS NULL AND users.active=true`  \n**Parâmetro:** `businessRules.risk.daysWithoutAttendance` (padrão: 30 dias)  \n\n### Inadimplência\n**Definição:** Contagem de pagamentos em atraso nas duas fontes de pagamento  \n**SQL:** `COUNT(*) FROM studentPayments WHERE status='overdue' AND dueDate < now() UNION COUNT(*) FROM contasReceber WHERE status='OVERDUE' AND dueDate < now()`  \n**Janela Temporal:** Atual (pagamentos vencidos)  \n\n## Regras de Negócio Centralizadas\n\n### Arquivo: `server/config/businessRules.ts` e `client/src/config/businessRules.ts`\n\n```typescript\nrisk: {\n  daysWithoutAttendance: 30,      // Dias sem presença = risco\n  attendanceRateThreshold: 0.6,   // Taxa mínima de presença\n  paymentOverdueDays: 7          // Dias de atraso = inadimplente\n},\n\ntimeWindows: {\n  attendanceWindow: 'current_month',\n  revenueWindow: 'current_month',\n  classAttendanceDays: 30\n},\n\ncache: {\n  dataFreshnessThreshold: 5 * 60 * 1000,  // 5 minutos\n  defaultStaleTime: 30 * 1000,            // 30 segundos\n  autoRefreshInterval: 60 * 1000           // 1 minuto\n}\n```\n\n## Sistema de Data Freshness\n\n### Componente: `DataFreshnessIndicator`\n- **Tooltip de Timestamp:** Mostra \"Atualizado às HH:mm:ss\"\n- **Badge de Status:** Verde (fresco), Amarelo (stale), Vermelho (muito stale)\n- **Botão de Refresh:** Aparece quando dados estão stale\n- **Limites:** 5min (stale), 10min (muito stale)\n\n### Lógica de Freshness\n```typescript\nconst isDataFresh = (Date.now() - lastUpdate) < businessRules.cache.dataFreshnessThreshold;\nconst isStale = timeSinceUpdate > businessRules.cache.dataFreshnessThreshold;\nconst isVeryStale = timeSinceUpdate > (businessRules.cache.dataFreshnessThreshold * 2);\n```\n\n## Segurança e Multitenancy\n\n### Filtros de Tenant\n-
