Estados e regras (simples)

attendance.status: 'confirmed' | 'present' | 'late' | 'absent' | null

confirmed = confirmou presença antes (app/aluno).

present/late/absent = resultado da chamada.

attendance.checked_in_at (QR ou clique direto).

Capacidade = classes.max_students.

Pendentes = alunos na turma sem present/late/absent no dia.

Em risco (para o dashboard) não é aqui, mas a chamada alimenta.

API (contratos enxutos)
Aulas do dia

GET /api/classes?date=YYYY-MM-DD
→ [ { id, name, instructor:{id,name}, start_time, duration, max_students, stats:{confirmed, present, late, absent, pending} } ]

stats é agregado em SQL com COUNT(*) FILTER (...).

Roster da aula

GET /api/classes/:id/roster?date=YYYY-MM-DD
→ [ { student_id, name, belt_level, confirmed: boolean, status: 'present'|'late'|'absent'|null } ]

Marcação individual

PATCH /api/attendance/:classId/:studentId
Body: { date, status, note? } → 200 { ok: true }

Marcação em lote

POST /api/attendance/bulk
Body: { date, classId, updates: [{ studentId, status }] } → 200

Iniciar/encerrar aula

POST /api/classes/:id/start { date }
POST /api/classes/:id/finish { date, finalizeAbsentRest: boolean }

SQL (agregados de contadores — exemplo)
-- stats por aula no dia
SELECT
  c.id,
  COUNT(*) FILTER (WHERE a.status = 'confirmed')      AS confirmed,
  COUNT(*) FILTER (WHERE a.status = 'present')        AS present,
  COUNT(*) FILTER (WHERE a.status = 'late')           AS late,
  COUNT(*) FILTER (WHERE a.status = 'absent')         AS absent,
  COUNT(*) FILTER (WHERE a.status IS NULL)            AS pending
FROM classes c
LEFT JOIN attendance a
  ON a.class_id = c.id AND DATE(a.date) = $1
WHERE c.tenant_id = $tenant AND c.day_of_week = EXTRACT(DOW FROM $1::date)
GROUP BY c.id;

UI/React (padrões rápidos)
Card da aula (lista do dia)
function ClassCard({ c, onOpen }:{
  c:{ id:number; name:string; start_time:string; instructor:{name:string}; max_students:number;
      stats:{confirmed:number; present:number; pending:number} };
  onOpen:(id:number)=>void;
}) {
  const pct = c.max_students ? Math.min(100, Math.round(c.stats.present*100/c.max_students)) : 0;
  return (
    <button onClick={()=>onOpen(c.id)} className="w-full text-left rounded-xl border p-3 hover:bg-slate-50">
      <div className="flex justify-between">
        <div className="font-medium">{c.name}</div>
        <div className="text-sm text-slate-500">{c.start_time} • {c.instructor?.name}</div>
      </div>
      <div className="mt-2 h-2 bg-slate-200 rounded">
        <div style={{width:`${pct}%`}} className="h-2 rounded bg-slate-900" />
      </div>
      <div className="mt-2 text-xs text-slate-600">
        Confirmados {c.stats.confirmed} • Presentes {c.stats.present} • Pendentes {c.stats.pending} / Cap {c.max_students}
      </div>
    </button>
  );
}

Linha do aluno (roster)
function RosterRow({ s, onSet }:{
  s:{ student_id:number; name:string; belt_level:string; confirmed:boolean; status:null|'present'|'late'|'absent' };
  onSet:(status:null|'present'|'late'|'absent')=>void;
}) {
  const btn = (val, label) => (
    <button
      onClick={()=>onSet(val)}
      className={`px-2 py-1 rounded border ${s.status===val ? 'bg-slate-900 text-white' : 'bg-white'}`}>
      {label}
    </button>
  );
  return (
    <tr className="border-t">
      <td className="py-2">{s.name} <span className="text-xs text-slate-500">• {s.belt_level}</span></td>
      <td className="text-xs">{s.confirmed ? "✅ Confirmado" : "—"}</td>
      <td className="flex gap-2 py-2">
        {btn('present','Presente')}{btn('late','Atraso')}{btn('absent','Falta')}
      </td>
    </tr>
  );
}

Bulk actions (topo do roster)

Botões: Selecionar confirmados, Marcar Presente, Marcar Falta, Limpar.

“Salvar” não precisa: auto-save por request, com toast/spinner discreto.

Fluxo de uso (simples)

Escolhe a data → vê cartões das aulas.

Abre uma aula → clica Iniciar aula.

Marca Presente/Atraso/Falta (ou Marcar confirmados como presente).

Ao final → Encerrar aula (restantes → falta opcional).

Os contadores e o Dashboard atualizam.

Acessibilidade & produtividade

Tudo clicável também com teclado (Tab/Enter).

Atalhos: P (Presente), A (Atraso), F (Falta) na linha focada.

Busca com Enter.

Feedback: “Auto-salvo ✓” e erro “Falha ao salvar — tentar de novo”.
