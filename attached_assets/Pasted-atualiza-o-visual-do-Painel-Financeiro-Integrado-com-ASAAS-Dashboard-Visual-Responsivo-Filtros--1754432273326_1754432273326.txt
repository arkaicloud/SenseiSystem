atualização visual do Painel Financeiro Integrado com ASAAS (Dashboard Visual, Responsivo + Filtros)
Contexto:
Estamos desenvolvendo o módulo financeiro do sistema SenseiSystem com integração total ao ASAAS. O painel deve exibir as cobranças, métricas financeiras e permitir busca e filtros avançados. Já temos integração com o ASAAS via API Key.

🎯 Objetivo:
Desenvolver a interface e backend do Painel Financeiro com base nos dados do ASAAS, incluindo:

Cobranças por aluno

Total recebido, pendente e em atraso

Taxa de inadimplência

Próximo vencimento

Filtros e busca por cliente

Responsividade total para desktop e mobile

🧠 Lógica Backend (Node.js):
GET /financeiro/sync

Conecta-se à API ASAAS

Rota segura com token .env (ASAAS_API_KEY)

Endpoint usado:

bash
Copiar
Editar
GET https://sandbox.asaas.com/api/v3/payments?limit=100
Headers: Authorization: Bearer <token>
Salva em cache local ou em memória para atualizar a visualização sem refazer chamadas desnecessárias

GET /financeiro/cliente/:cpf

Busca cobranças filtradas por CPF (ou nome)

Utiliza query local ou direta no ASAAS com:

bash
Copiar
Editar
GET https://sandbox.asaas.com/api/v3/customers?cpfCnpj=<cpf>
GET /financeiro/resumo

Calcula: total recebido, total em aberto, em atraso, inadimplência, próximo vencimento

💄 UI/UX (Frontend React):
Use TailwindCSS + ícones Lucide + shadcn/ui

Cards com cores distintas (verde, vermelho, amarelo) conforme status

Barra lateral mantém menu “Financeiro > Contas a Receber”

Utilize DatePicker, Combobox, Toggle para filtros

Layout responsivo: exibição em grid para desktop, colunas para mobile

Exibir gráfico de pizza ou linha para inadimplência (opcional)

🛡️ Segurança:
Validar token ASAAS no backend

Não expor o token no frontend

Restringir requisição por usuário logado (admin apenas)
