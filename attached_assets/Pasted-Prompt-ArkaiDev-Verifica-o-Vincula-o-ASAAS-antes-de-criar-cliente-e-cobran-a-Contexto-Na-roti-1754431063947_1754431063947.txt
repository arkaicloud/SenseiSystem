Prompt ArkaiDev — Verificação + Vinculação ASAAS antes de criar cliente e cobrança
Contexto:
Na rotina de aprovação de aluno no SenseiSystem, após o preenchimento do onboarding e antes da criação automática de cliente/cobrança no ASAAS, é necessário implementar uma função inteligente que primeiro verifica se o cliente já existe no ASAAS (pelo CPF/CNPJ ou e-mail) e, caso positivo, apenas vincula os dados existentes ao cadastro interno, evitando duplicações.

🎯 Objetivo
Antes de:

Criar um novo cliente ASAAS

Gerar cobrança automática

✅ Verificar se o responsável financeiro do aluno já existe no ASAAS
✅ Se já existir, usar esse customerId e apenas gerar a cobrança
✅ Se já houver cobrança gerada, apenas vincular essa cobrança ao banco interno

async function getOrCreateAsaasCustomer(responsavel) {
  const cpf = responsavel.cpf.replace(/\D/g, '');

  const search = await axios.get(`${ASAAS_BASE}/customers?cpfCnpj=${cpf}`, headers);

  if (search.data?.data?.length > 0) {
    return search.data.data[0].id;
  }

  const newCustomer = await axios.post(`${ASAAS_BASE}/customers`, {
    name: responsavel.nome,
    cpfCnpj: cpf,
    email: responsavel.email,
    mobilePhone: responsavel.telefone,
    postalCode: responsavel.cep,
    address: responsavel.endereco,
    addressNumber: responsavel.numero
  }, headers);

  return newCustomer.data.id;
}

async function createOrSyncCobranca(aluno, plano) {
  const customerId = await getOrCreateAsaasCustomer(aluno.responsavel);

  // Buscar pagamentos existentes
  const { data } = await axios.get(`${ASAAS_BASE}/payments?customer=${customerId}`, headers);
  const pagamentos = data.data;

  const pagamentoExistente = pagamentos.find(p => 
    p.status !== 'RECEIVED' && p.value === plano.valor
  );

  if (pagamentoExistente) {
    // Apenas vincula
    await saveTituloNoBanco(pagamentoExistente);
  } else {
    // Cria nova cobrança
    const nova = await axios.post(`${ASAAS_BASE}/payments`, {
      customer: customerId,
      billingType: "BOLETO",
      value: plano.valor,
      dueDate: plano.vencimento
    }, headers);

    await saveTituloNoBanco(nova.data);
  }
}
