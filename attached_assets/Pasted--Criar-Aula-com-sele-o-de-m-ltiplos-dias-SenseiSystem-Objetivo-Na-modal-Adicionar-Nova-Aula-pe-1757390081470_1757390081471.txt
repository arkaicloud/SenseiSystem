“Criar Aula” com seleção de múltiplos dias (SenseiSystem)
Objetivo

Na modal Adicionar Nova Aula, permitir selecionar vários dias da semana para a mesma aula e horário (ex.: “Aula Manhã” seg/ter/sex/sáb às 07:00 ou “Todos os dias”).

Ao salvar, criar N registros em classes (um por dia selecionado) numa única transação.

Prevenir duplicatas (mesmo tenant_id + name + instructor_id + day_of_week + start_time).

Mostrar preview dos dias/horário antes de salvar.

1) Decisão de modelo (mínima mudança)

Manter classes como está (um registro por dia_da_semana).

Implementar endpoint de batch que recebe days[] e cria uma linha por dia.

(Opcional futuro) Normalizar para class_schedules, mas não agora.

2) Backend — rota de batch insert + idempotência
2.1 Índice único contra duplicatas
-- Drizzle/SQL (exemplo SQL puro)
CREATE UNIQUE INDEX IF NOT EXISTS idx_unique_class_per_day
ON classes(tenant_id, name, instructor_id, day_of_week, start_time);

2.2 Rota
// server/routes/classes.ts
import { Router } from "express";
import { authenticateJWT } from "../auth";
import { db } from "../db";
import { sql } from "drizzle-orm";

export const classesRouter = Router();

/**
 * POST /api/classes/batch
 * body: {
 *   name: string,
 *   description?: string,
 *   instructorId?: number | null,
 *   days: number[],              // 0..6 (dom..sáb)
 *   startTime: string,           // "HH:mm"
 *   duration: number,            // minutos
 *   maxStudents?: number | null
 * }
 */
classesRouter.post("/batch", authenticateJWT, async (req, res) => {
  const tenantId = (req.user as any).tenant_id;
  const { name, description, instructorId, days, startTime, duration, maxStudents } = req.body;

  // validações simples (zod no controlador é bem-vindo)
  if (!name || !Array.isArray(days) || !days.length) return res.status(400).json({error:"Selecione ao menos um dia"});
  if (!/^(?:[01]\d|2[0-3]):[0-5]\d$/.test(startTime)) return res.status(400).json({error:"Horário inválido"});

  try {
    await db.transaction(async (tx) => {
      for (const d of days) {
        // idempotência: se já existe, ignora (ON CONFLICT DO NOTHING)
        await tx.execute(sql`
          INSERT INTO classes (tenant_id, name, description, instructor_id, day_of_week, start_time, duration, max_students)
          VALUES (${tenantId}, ${name}, ${description ?? null}, ${instructorId ?? null}, ${d}, ${startTime}, ${duration}, ${maxStudents ?? null})
          ON CONFLICT ON CONSTRAINT idx_unique_class_per_day DO NOTHING;
        `);
      }
    });

    // retorna os registros criados/confirmados
    const rows = await db.execute(sql`
      SELECT id, name, instructor_id, day_of_week, start_time, duration, max_students
      FROM classes
      WHERE tenant_id=${tenantId}
        AND name=${name}
        AND start_time=${startTime}
        AND duration=${duration}
        AND (${sql.raw(days.map(d=>`day_of_week=${d}`).join(" OR "))})
      ORDER BY day_of_week ASC;
    `);

    res.json({ ok: true, items: rows.rows });
  } catch (e:any) {
    res.status(500).json({ error: "Falha ao criar aulas", detail: e.message });
  }
});


Se o Drizzle/ORM não expõe ON CONFLICT fácil, use SQL cru como acima ou insertMany + try/catch por dia.

// src/pages/aulas/schema.ts
import { z } from "zod";

export const NewClassSchema = z.object({
  name: z.string().min(3, "Informe o nome da aula"),
  description: z.string().optional(),
  instructorId: z.number().int().optional().nullable(),
  days: z.array(z.number().int().min(0).max(6)).min(1, "Selecione ao menos um dia"),
  startTime: z.string().regex(/^([01]\d|2[0-3]):[0-5]\d$/, "Formato HH:mm"),
  duration: z.number().int().min(15).max(240),
  maxStudents: z.number().int().min(1).max(200).optional().nullable(),
});
export type NewClassInput = z.infer<typeof NewClassSchema>;

3.2 Componente DayPicker (chips + atalhos)
// src/components/aulas/DayPicker.tsx
const DAYS = [
  { v:0, l:"Dom" }, { v:1, l:"Seg" }, { v:2, l:"Ter" },
  { v:3, l:"Qua" }, { v:4, l:"Qui" }, { v:5, l:"Sex" }, { v:6, l:"Sáb" },
];

export function DayPicker({ value, onChange }:{
  value:number[]; onChange:(v:number[])=>void;
}) {
  const toggle = (d:number) =>
    onChange(value.includes(d) ? value.filter(x=>x!==d) : [...value, d].sort((a,b)=>a-b));
  const setAll   = () => onChange(DAYS.map(d=>d.v));
  const setWeek  = () => onChange([1,2,3,4,5]);
  const setWeekend = () => onChange([0,6]);
  const clear = () => onChange([]);

  return (
    <div className="space-y-2">
      <div className="flex gap-2 flex-wrap">
        {DAYS.map(d=>(
          <button key={d.v}
            type="button"
            onClick={()=>toggle(d.v)}
            className={`px-3 py-1.5 rounded-md border ${value.includes(d.v) ? "bg-slate-900 text-white" : "bg-white"}`}>
            {d.l}
          </button>
        ))}
      </div>
      <div className="text-sm flex gap-2 flex-wrap">
        <button type="button" className="underline" onClick={setAll}>Todos os dias</button>
        <button type="button" className="underline" onClick={setWeek}>Seg a Sex</button>
        <button type="button" className="underline" onClick={setWeekend}>Sáb/Dom</button>
        <button type="button" className="underline text-slate-500" onClick={clear}>Limpar</button>
      </div>
    </div>
  );
}
