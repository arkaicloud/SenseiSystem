VYTA — Design System
Design system completo extraído do app VYTA. Use como referência para implementar o mesmo visual em outros projetos React Native (Expo) ou Web.

1. IDENTIDADE
Nome: VYTA
Tom visual: Dark mode com acentos azul elétrico — atletismo, performance, foco
Tom de voz: Direto, motivador, sem enrolação — como um bom personal trainer
Idioma: Português do Brasil

8. ANIMAÇÕES
8.1 Palavra motivacional (fade + spring)
// Animated.Value para opacidade e escala
const wordOpacity = useRef(new Animated.Value(0)).current
const wordScale   = useRef(new Animated.Value(0.85)).current
// Entrada da palavra
Animated.parallel([
  Animated.timing(wordOpacity, {
    toValue: 1, duration: 400, useNativeDriver: true
  }),
  Animated.spring(wordScale, {
    toValue: 1, friction: 7, tension: 80, useNativeDriver: true
  }),
]).start()
// Saída após pausa de 700ms
Animated.timing(wordOpacity, {
  toValue: 0, duration: 300, useNativeDriver: true
}).start()
8.2 Pontos pulsantes (sequência)
// 3 Animated.Values para os dots
const [dot1, dot2, dot3] = [
  useRef(new Animated.Value(0.3)).current,
  useRef(new Animated.Value(0.3)).current,
  useRef(new Animated.Value(0.3)).current,
]
// Loop sequencial com delay entre cada dot
const animDot = (dot: Animated.Value, delay: number) =>
  Animated.loop(
    Animated.sequence([
      Animated.delay(delay),
      Animated.timing(dot, { toValue: 1, duration: 300, useNativeDriver: true }),
      Animated.timing(dot, { toValue: 0.3, duration: 300, useNativeDriver: true }),
    ])
  ).start()
animDot(dot1, 0)
animDot(dot2, 200)
animDot(dot3, 400)

15. CHECKLIST DE CONSISTÊNCIA
Ao implementar uma nova tela, verificar:

 Usa useSafeAreaInsets() — sem padding fixo no topo/base
 Hero com LinearGradient sobre imagem (não cor sólida)
 fontFamily sempre da família Inter (nunca fontWeight)
 Cards com borderRadius: 16 e borderColor: Colors.border
 Botões CTA com borderRadius: 24 e backgroundColor: Colors.primary
 Pressed state com opacity: 0.9 em todos os Pressable
 paddingBottom: 100 no ScrollView para não ficar atrás da tab bar
 Imagens com expo-image + placeholder={{ color: "#1A1A1A" }} + transition={250}
 Inset web: Platform.OS === "web" ? 67 : 0 no topo
 Ícones do Ionicons — sem texto nos botões de navegação
